# devroom

Адаптивное сообщество разработчиков на React, TypeScript и SQLite. В проекте есть лента публикаций, сообщества по интересам, регистрация и вход по JWT, создание, просмотр, редактирование и удаление публикаций, а также защищённая админ-панель для управления пользователями и публикациями.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```sh
npm install
```

Для локальной разработки достаточно запустить приложение сразу. Для постоянного JWT-секрета скопируйте `.env.example` в `.env`; без `JWT_SECRET` сервер автоматически создаст локальный секрет в `data/`. Перед production обязательно задайте свой JWT-секрет длиной не менее 32 символов:

```sh
npm run dev
```

Vite запустит интерфейс на `http://localhost:5173`, API — на `http://localhost:3001`. База SQLite создаётся автоматически в `data/devroom.sqlite`; первые публикации добавляются в базу при первом старте.

Для production-сборки интерфейса используйте `npm run build`, для запуска API — `npm start`. Если интерфейс размещён отдельно от API, задайте `VITE_API_URL` (адрес API) до сборки. Перед публикацией приложения задайте `NODE_ENV=production`, настройте собственный `JWT_SECRET` и постоянное хранилище базы данных для выбранного хостинга.

## Основные маршруты

- `/` — лента публикаций с серверной пагинацией, поиском и сортировкой по популярности/новизне.
- `/communities` — сообщества и фильтр по темам.
- `/posts/:id` — просмотр публикации.
- `/submit` — создание публикации (требуется вход).
- `/login` и `/register` — вход и регистрация.
- `/admin` — управление пользователями, ролями и публикациями (только для администраторов).

Чтобы выдать администраторские права существующему аккаунту, запустите API один раз, зарегистрируйте аккаунт и выполните `npm run admin:promote -- user@example.com`. После этого выйдите из приложения и войдите снова, чтобы обновить роль в профиле. Обычная регистрация никогда не выдаёт права администратора.

Администратор может просматривать и искать пользователей/публикации, менять роли пользователей, удалять участников и модерировать любые публикации. Защита проверяется на сервере. Последнего администратора нельзя понизить; администратор не может удалить собственный аккаунт или другого администратора напрямую.

Пользовательские пароли хранятся в виде bcrypt-хеша. API выдаёт JWT с ограниченным сроком действия и проверяет авторство для операций редактирования и удаления. Списки публикаций и данных админ-панели загружаются страницами; API возвращает записи вместе с общим количеством и числом страниц.

## Структура проекта

- `src/` — React-интерфейс и общие стили.
- `src/features/admin/` — интерфейс и стили админ-панели.
- `server/` — API, SQLite и утилита назначения администратора.
- `public/` — статические файлы приложения.
- `data/` — локальная база SQLite и JWT-секрет; каталог исключён из Git.
